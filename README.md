# 🐍 Python Workspace

A personal workspace for learning, practicing, and experimenting with Python. It holds my code from exercises, small programs, and mini-projects, organized so it's easy to revisit and build on.

## 📌 About

This repository is where I work through Python from the basics to more advanced topics. Each folder or file is a practice session: a concept I studied, a problem I solved, or a small program I built to test an idea.

## 🎯 Goals

- Build a strong foundation in core Python
- Practice data structures, algorithms, and problem solving
- Write clean, readable, well-documented code
- Keep a record of my learning progress over time

## 📁Repository Includes

- Basic Introduction,Loops,Inheritence
- DSA,Object Oriented Programming
- Statistics(Pandas,Numpy,DataFrame)
-Webscraping,API,Python Web, Python MongoDB

## 🛠️ Getting Started

**Prerequisites:** Python 3.12 ([download](https://www.python.org/downloads/))

```bash
# Clone the repository
git clone https://github.com/MuhammadAzlan/Python-Workspace.git

# Move into the project folder
cd Python-Workspace

# Run any script
python path/to/script.py
#Run .ipynb file in terminal
jupyter execute notebook.ipynb
```

## 📚 Learning Resources

### ⭐ Recommended: 30 Days of Python

[**30-Days-Of-Python**](https://github.com/Asabeneh/30-Days-Of-Python) by Asabeneh is one of the best open-source resources for learning Python. It is a structured 30-day challenge that covers:

- Python basics, data types, and operators
- Conditionals, loops, and functions
- Modules, list comprehensions, and decorators
- Error handling, file handling, and regular expressions
- Working with `pip`, virtual environments, web scraping, and APIs
- Introductions to databases and data analysis

Each day has clear explanations, examples, exercises, and solutions, which makes it a good fit for beginners as well as people refreshing their skills. I use it as the main reference for this workspace.

🔗 https://github.com/Asabeneh/30-Days-Of-Python
